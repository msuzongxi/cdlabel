Export labeled data

Admin only. One CSV row represents one paragraph × labeler annotation. The export contains gates, all six dimensions, all 32 attributes, optional values/evidence, notes, and source metadata.

CSV structure

Dimension and attribute columns are binary: 1 = selected/present, 0 = not selected/present. Gate columns retain YES / NO / UNCLEAR. A blank eligible value means the annotation is still an unresolved draft.

The default export is Calibration + Submitted only. “All labelers” creates separate rows for each labeler's annotation; it does not merge or adjudicate their labels.
